# WitherUtils examples — how to use them

`examples/` contains the class-pattern examples extracted from the supplied `EXAMPLES.md`. They illustrate typical responsibilities and code shapes for:
- mod entry/initialization;
- deferred registration;
- block logic and BlockEntity;
- menus and screens;
- custom renderers;
- items/tools;
- networking;
- recipes/serializers;
- datagen.

These are reference patterns, not guaranteed drop-in implementations. Verify imports, method signatures, event registration, NeoForge version, project base classes and existing local conventions before using them. Do not copy code blindly or introduce duplicates.

The complete original example document is preserved at `source_references/EXAMPLES.original.md`.
