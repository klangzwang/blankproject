# Aufgabenbezogener Brain-Kontext

Dieser Bereich ist für getrennte, aufgabenbezogene Arbeitsstände gedacht. Lege einen neuen Unterordner pro eigenständiger Migration an, z. B. mit einer eindeutigen Task-ID oder UUID, sofern die AI-Studio-Umgebung dies unterstützt.

Empfohlene Inhalte:
- `task.md`
- `frontend_analysis.md`
- `existing_code_analysis.md`
- `migration_mapping.md`
- `implementation_plan.md`
- `walkthrough.md`

Die Vorlagen liegen in `.aistudio/templates/`.

## Regeln
- Keine fiktiven Session-IDs oder Beispiel-Logs als echte Historie anlegen.
- Aufgabenordner voneinander trennen.
- Dauerhaft gültige Architektur-Fakten in `knowledge/` pflegen, nicht nur im Brain-Ordner.
- Temporäre Logs und Transkripte nicht als Projektwissen behandeln.
- Brain-Dateien ersetzen nicht die tatsächliche Prüfung des aktuellen Quellcodes.
