# Workflow-Index

Wähle für jede Aufgabe den passenden Ablauf. Bei einer vollständigen Frontend-zu-Mod-Migration diese Reihenfolge verwenden:

1. `analyze_frontend.md`
2. `analyze_existing_code.md`
3. `map_frontend_to_minecraft.md`
4. `create_migration_plan.md`
5. **Menschliche Freigabe**
6. `execute_migration.md`
7. `verify_migration.md`

Bei einem Fehler nach Umsetzung zusätzlich `troubleshoot_migration.md`.

## Aufrufhinweis

Im AI Studio Plan Mode den Workflow anhand seines Dateipfads referenzieren, zum Beispiel: „Führe `.aistudio/workflows/analyze_frontend.md` für den aktuell geöffneten Prototyp aus.“ Falls die Oberfläche einen anderen Mechanismus zum Einbinden von Projektanweisungen bereitstellt, diesen nutzen. Keine nicht bestätigte Slash-Command- oder Plugin-Registrierung voraussetzen.
