# Workflow: project audit

1. Read `.aistudio/AGENTS.md` and the relevant knowledge docs.
2. Inspect repository status, package scripts, Gradle files, TypeScript config, Vite config and entry points.
3. Map the existing files under the three work areas; do not infer from an old snapshot.
4. Identify existing stubs, duplicate implementations, asset roots and tests.
5. Report confirmed facts separately from assumptions and gaps.
6. Do not modify files during an audit unless explicitly requested.
